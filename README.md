# Xpose Advertising — Modern Website Redevelopment

A modern, responsive, static website redesign for Xpose Advertising.

## Stack
- Semantic HTML5
- CSS3 with custom design tokens, responsive grid, animations
- Vanilla JavaScript (no framework/build step)
- Local SVG artwork for lightweight visual assets
- Google Fonts loaded from the web

## Pages
- `index.html` — Home
- `about.html` — About Xpose
- `services.html` — Services
- `portfolio.html` — Portfolio / work categories
- `clients.html` — Client sectors
- `contact.html` — Contact / enquiry form
- `404.html` — Not found page

## Run locally
Open `index.html` directly, or use any static server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deployment
The project is static and can be deployed to Netlify, Vercel, GitHub Pages, cPanel/static hosting, or any normal web server.

## Notes
The content structure is based on the current Xpose Advertising website: its advertising, promotions, event management, rural outreach, product branding, digital marketing and corporate client positioning. The visual system is intentionally new rather than a copy of the existing UI.
